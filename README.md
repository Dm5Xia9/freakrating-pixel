# FreakRating Stencil

Скрипт Tampermonkey для пиксель-баттла [FreakRating](https://freakrating.lol/). В 3D-комнате «Художка» трафарет-картинка лежит прямо на холсте. Скрипт подсказывает нужный цвет под прицелом, показывает прогресс и стрелку к ближайшей клетке. Сам он ничего не рисует: кисть остаётся в руках игрока.

## Установка

1. Поставь расширение [Tampermonkey](https://www.tampermonkey.net/).
2. Открой [скрипт FreakRating Stencil](https://raw.githubusercontent.com/Dm5Xia9/freakrating-pixel/main/tampermonkey/freakrating-stencil.user.js) и нажми **Install** (или **Обновить**). Дальше Tampermonkey сам подтягивает новые версии.
3. Открой FreakRating и зайди в «Художку».

## Управление

| Клавиши | Действие |
|---|---|
| **Shift+Y** | панель: список трафаретов, импорт, координаты, настройки |
| **Shift+T** | показать или скрыть трафарет на полу |
| **Shift+H** | режим установки: призрак ходит за прицелом. ЛКМ или Enter ставит, стрелки сдвигают на клетку (с Shift — на 10), Esc отменяет |

- **Добавить картинку**: перетащи PNG или JPG на панель, вставь её через Ctrl+V или кликни по рамке. Цвета подгоняются к палитре сервера (ближайший цвет в OKLab), по желанию с дизерингом. Пиксели с прозрачностью меньше половины не трогаются. Большие картинки по умолчанию ужимаются до 128 клеток по ширине.
- **Метки на полу**: кружок — клетку надо покрасить, красный крест — она закрашена чужим цветом, готовые клетки не отмечаются (по желанию — бледно-зелёным). Контуры клеток видны вблизи и пропадают при отдалении.
- **Подсказка под прицелом**: цвет, номер в палитре, номер быстрого слота и «в кисти», если этот цвет уже выбран. Опция «Сам выбирать цвет» переключает кисть на цвет клетки под прицелом, но не во время мазка.
- **Верхняя полоса**: сколько клеток готово, сколько надо и сколько чужих, остаток краски, примерное время и какие цвета нужнее всего в зоне кисти (46 м).
- **Стрелка** указывает на ближайшую клетку к покраске: сначала цвета, который уже в кисти, если он в зоне досягаемости.
- **Порча**: если готовые клетки закрасили чужим, игра покажет тост.
- **Обмен**: «Копировать код» кладёт в буфер строку `FRST1:…`. Друг вставляет её в открытую панель (Ctrl+V).

Трафареты хранятся в `localStorage` браузера. Цвета записаны по именам, поэтому если сервер поменяет палитру, трафарет переведётся сам.

## Разработка

```bash
npm test        # юнит-тесты: квантование, RLE, раскладка клеток по тайлам, статусы
npm run build   # src/core.js + src/main.js → tampermonkey/freakrating-stencil.user.js
```

- `src/core.js` — логика без DOM: палитра, OKLab, квантование, код трафарета, сравнение с холстом.
- `src/main.js` — подключение к движку (как во FreakRating DJ: `import()` того же `engine-*.js` и обёртка `WorldEngine.prototype.renderScene`), меш на полу (`renderOrder` 4, метки рисует шейдер `MeshBasicMaterial.onBeforeCompile`), HUD.
- В игровой слой холста (`room.layer`) скрипт ничего не пишет, только читает массивы `colors` тайлов.
- `FRStencil.debug()` в консоли выдаёт реальные `rules`, `floor`, `scale` и границы комнаты.
